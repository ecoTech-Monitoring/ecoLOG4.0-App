# enviLog 4.0 — App (Hosting)

Dies ist **nur die fertige, ausgelieferte App** (der Build). Der Quellcode,
die Modularchitektur und die Historie liegen im getrennten Projekt-Repository
`blueshell` (privat).

- Live (GitHub Pages): siehe Repo-Einstellungen → Pages
- Einstieg: `index.html` leitet auf `BS-eco40.html` (die eigentliche App)
- Basis: GeoPrecision BlueShell 27F (Build 21.07.2026), ecoTech-Ausgabe

## Aktualisieren

Neuen Build aus dem `blueshell`-Projekt hierher kopieren
(`bs-eco40/dist/*`, ohne die lokalen Starter `eco40-starten.bat` /
`serve-standalone.ps1`), committen, pushen. GitHub Pages veröffentlicht
automatisch.

## Nutzung auf dem Smartphone

- **Android:** in Chrome öffnen → Menü → „App installieren" → Launcher-Icon „enviLog 4.0".
- **iPhone/iPad:** Web Bluetooth fehlt im System-Browser (Apple-Vorgabe).
  Die kostenlose App **Bluefy** (App Store) öffnen und die Adresse dort laden.
- **Desktop:** Chrome, Edge oder Opera. Kein Firefox (kein Web Bluetooth).
